Sample-only demo
This public page is a UI demo, not a password vault. All entries are fictional, held in memory and reset on refresh. There is no form for real credentials, no server storage and no account connection.
Try searching or revealing a fictional password.

Designed to stay local

The Python app saves encrypted passwords in SQLite. Saving the same site updates its existing entry instead of creating a duplicate.

A cleaner desktop

A green-and-cream interface, searchable account list, password generation and timed hiding bring the local app into the same visual family.

Learning, not a guarantee

The desktop key is stored beside the database. There is no master password. Use a vetted password manager for important credentials.
